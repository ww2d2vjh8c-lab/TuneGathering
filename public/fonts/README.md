# Fonts

Bundled so the app works offline on a LAN. All are open-licensed and come from [google/fonts](https://github.com/google/fonts):

| File | Family | License | Used for |
| --- | --- | --- | --- |
| `Anton-Regular.ttf` | Anton | SIL OFL 1.1 (`OFL.txt`) | Big display type ("SYNCED", logo) |
| `BarlowCondensed-*.ttf` | Barlow Condensed | SIL OFL 1.1 | Menu tabs, labels, list rows |
| `Barlow-*.ttf` | Barlow | SIL OFL 1.1 | Body text, chat |
| `Yellowtail-Regular.ttf` | Yellowtail | Apache 2.0 | Script header in the room menu |

## Optional: Pricedown

The classic GTA logo face (Pricedown, by Typodermic) is **not** bundled because its redistribution terms are unclear.
If you own a copy, drop it here as `pricedown.otf` (or install it system-wide) and the display type switches to it
automatically. Everything falls back to Anton otherwise.
